# 💈 Black Gold – Site de Barbearia

## 📌 Sobre o projeto

O projeto **Black Gold – Barbearia** consiste no desenvolvimento de uma página web para representar uma barbearia moderna, oferecendo aos clientes uma maneira prática e visualmente atrativa de conhecer os serviços disponíveis.

A página será utilizada como uma vitrine digital da barbearia, permitindo apresentar sua identidade visual, divulgar os serviços e preços, mostrar fotos do ambiente e disponibilizar informações de contato.

## 🎯 Objetivo

O principal objetivo é fortalecer a presença digital da barbearia, facilitar o acesso às informações e proporcionar uma experiência agradável aos visitantes.

Com essa página, os clientes poderão conhecer melhor o estabelecimento, consultar os serviços oferecidos e encontrar os meios de entrar em contato para solicitar um atendimento.

## ⚙️ Tecnologias utilizadas

- **HTML5:** responsável pela estrutura e organização do conteúdo.
- **CSS3:** utilizado para estilização, cores, layouts, efeitos visuais e responsividade.

## ✨ Principais funcionalidades

- Página inicial com apresentação da barbearia.
- Seção sobre a história e identidade do estabelecimento.
- Exibição dos serviços e respectivos preços.
- Galeria de imagens.
- Área de contato com formulário visual.
- Layout adaptável para computadores, tablets e celulares.

## 🚀 Finalidade do projeto

Além de servir como uma apresentação digital de uma barbearia, este projeto também tem como finalidade desenvolver e aprimorar conhecimentos em desenvolvimento web, principalmente na utilização de HTML5 e CSS3.

O projeto poderá receber futuras atualizações, incluindo funcionalidades com JavaScript, agendamento online e integração com WhatsApp.
